# Uploader Bot

Telegram downloader/uploader bot based on the supplied DiskWala + Terabox project.

## Providers
- DiskWala
- Terabox
- YouTube

## Runtime
Node.js 18.17+ with zero npm dependencies.

## Configuration
Copy `.env.example` to `.env` locally. Never commit secrets.

The existing working provider/download engine is being preserved and audited rather than rewritten.
